What each mode does

Every mode runs the same retrieval core — the difference is how many times it searches, whether it reads the open web, and how long it is allowed to take. Nothing is hidden: the stage timeline above each answer shows exactly what ran.

Deep

Procedures end to end — fees, deadlines, which office, how to appeal.

  1. Plan — split into sub-questions
  2. Retrieve + grade — repeats while gaps remain
  3. Navigate — follows links inside gov portals, 2 levels down
  4. Gap analysis — asks what is still unanswered, searches again
  5. Self-verify — re-checks claims it is unsure of against the web
  6. Write, then revise — rewrites if verification contradicts it

Always on, in every mode: answers cite only retrieved text; citations are checked to resolve before you see them; when nothing scores well enough the assistant says so instead of guessing; and central law is labelled separately from state law, because a state Act does not apply outside its state.

Ask about your rights under Indian law. I search the Constitution, about 1,000 central Acts, and the 2024 criminal codes (BNS, BNSS, BSA) that replaced the IPC, CrPC and Evidence Act — then cite the exact section.

For procedures I can also read official government sites for the current fee, deadline and portal. Ask in English, Hindi, or Hinglish.
